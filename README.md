# Memory Card Game 2.0

记忆翻牌游戏是一个基于Python和Tkinter开发的卡牌记忆游戏。

## 功能特性

### 核心游戏功能
- 经典记忆翻牌游戏玩法
- 多种难度级别
- 计时挑战模式
- 成就系统
- 积分奖励机制

### 用户系统
- 用户账户管理
- 游戏进度保存
- 战绩统计
- 个人资料展示

### 商城系统
- 道具购买
- 积分消费
- 道具使用

### 管理员功能
- 特殊登录机制（点击Logo 5次进入管理员模式）
- 用户信息查看（密码、历史记录、成就、积分、道具）
- 用户密码重置
- 数据导出（JSON/CSV格式）

### 说明书功能
- 游戏详细介绍
- 玩法说明
- 界面功能介绍
- 成就系统说明
- 积分获取方式
- 游戏技巧提示

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行游戏

```bash
python main.py
```

## 管理员登录

有两种方式可以访问管理员功能：

1. 在登录界面点击游戏Logo 5次进入管理员模式
2. 使用管理员账户登录：
   - 用户名：admin
   - 密码：123456

## 项目结构

```
Memory_Card-game2.0/
├── core/              # 核心游戏逻辑
├── gui/               # 图形界面组件
├── managers/          # 数据管理器
├── data_structures/   # 数据结构实现
├── data/              # 游戏数据文件
├── assets/            # 游戏资源文件
├── utils/             # 工具函数
└── tests/             # 测试文件
```
