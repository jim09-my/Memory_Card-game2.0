# 记忆卡牌游戏 v2.0.0

这是一个基于Python和Tkinter开发的记忆翻牌游戏。

## 系统要求

- Windows 7 或更高版本
- Python 3.7 或更高版本（如果从源代码运行）

## 快速开始

### 方法一：直接运行（推荐）
1. 双击 `run.bat` 文件即可直接运行游戏

### 方法二：使用安装脚本
1. 双击 `install_and_run.bat` 文件
2. 脚本将自动安装依赖并运行游戏

### 方法三：手动运行
1. 双击 `MemoryCardGame.exe` 文件直接运行游戏

## 游戏特性

- 经典记忆翻牌游戏玩法
- 多种难度级别（普通模式、终极模式）
- 计时挑战模式
- 成就系统（28项成就等待解锁）
- 积分奖励机制
- 用户账户管理
- 商城系统（可用积分购买道具）
- 游戏历史记录
- 个人资料展示

## 管理员功能

有两种方式可以访问管理员功能：

1. 在登录界面点击游戏Logo 5次进入管理员模式
2. 使用管理员账户登录：
   - 用户名：admin
   - 密码：123456

管理员可以：
- 查看所有用户信息
- 重置用户密码
- 导出用户数据（JSON/CSV格式）

## 操作说明

- 点击两张卡片进行翻牌
- 找到相同的卡片对
- 在限定时间内完成所有匹配获胜
- 使用道具帮助通关

## 道具系统

- 透视眼：短暂显示一对未配对卡片的位置
- 时间胶囊：延长30秒剩余时间
- 防洗牌护盾：阻止一次因连续失败触发的洗牌
- 时间静止：在终极挑战模式中冻结计时10秒

## 成就系统

游戏中包含28项成就，分为以下几类：
- 入门成就
- 成长成就
- 技术成就
- 连胜成就
- 活跃成就

## 积分获取方式

- 完成游戏获得基础积分
- 解锁成就获得奖励积分
- 连续登录获得奖励积分
- 特殊挑战获得额外积分
